# App Input Switcher

切到终端，自动英文；离开终端，恢复原来的输入法。

App Input Switcher 是一个基于 Swift 和 macism 的 macOS 输入法自动切换工具，帮助你在终端与其他应用之间切换时，减少手动调整输入法的操作。

## 为什么做这个项目？

使用中文输入法聊天或写作后，切回终端输入命令，经常会发现需要手动切换到英文。

希望：

- 进入终端时，自动切换到英文输入法。
- 离开终端时，恢复进入终端前使用的输入法。

让命令输入保持顺畅，不打断原中文输入习惯。

## 当前功能

- 支持 macOS。
- 终端应用获得焦点时，自动切换到指定的英文输入源。
- 切换到其他应用时，恢复进入终端前保存的输入源。
- 使用 Swift 处理应用切换逻辑，调用 macism 读取和切换输入源。


## 使用示例

假设你正在使用中文输入法：

1. 在其他应用中输入中文。
2. 切换到终端，输入法自动切换为英文。
3. 输入并执行命令。
4. 切换回其他应用，输入法恢复为进入终端前的中文输入法。

如果进入终端前已经使用英文输入法，离开后仍恢复为该英文输入法。

## 环境要求

- macOS。
- 已安装 macism。
- 本地编译或运行 Swift 代码所需的开发环境。
- 系统中已添加需要使用的英文输入源。

具体支持的 macOS 版本和终端应用，以项目实际测试结果为准。

## 安装

### 1. 安装 macism

如果已安装 Homebrew，可以执行：

```sh
brew tap laishulu/homebrew
brew install macism
```

### 2. 获取英文输入源 ID

先手动切换到你希望在终端中使用的英文输入法，然后执行：

```sh
macism
```

保存输出的输入源 ID，供程序配置使用。

可以通过以下命令单独检查输入源切换是否正常，将占位内容替换为实际 ID：

```sh
macism <英文输入源ID>
```

### 3. 配置并启动程序

在 Swift 实现中确认以下内容：

| 配置内容 | 说明 |
| --- | --- |
| 目标终端应用 | 需要触发自动切换的终端应用标识 |
| 英文输入源 ID | 通过 macism 查询得到的目标输入源 ID |
| macism 可执行文件路径 | 程序调用 macism 时使用的路径 |

具体变量名和配置方式以源码为准。

> 待补充：项目源码的获取方式、实际 Swift 文件名，以及编译、启动和停止命令。

## 工作原理

```text
其他应用 → 终端应用
    保存当前输入源
    切换到指定英文输入源

终端应用 → 其他应用
    恢复之前保存的输入源
```

这里的“恢复”指恢复进入终端前使用的输入源，而不是恢复目标应用各自的历史输入法。

## 当前范围

- 暂时仅支持 macOS。
- 当前以终端应用为切换目标。
- 当前功能不包含按应用分别配置输入法规则。
- 当前说明仅涵盖系统输入源切换，不承诺恢复输入法内部的候选状态或中英文模式。
